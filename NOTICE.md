# credits and attribution

this mod modifies an existing payware aircraft. it is not standalone and it does not
replace the base product. you need the Sim Federation Challenger 350 installed for any
of it to do anything.

## avionics code

`FMC.js`, `WT21_FMC.html` and `WT21_PFD.html` are modified builds of the Working Title
WT21 avionics, which is published by Microsoft in the
[msfs-avionics-mirror](https://github.com/microsoft/msfs-avionics-mirror) repository
under the MIT license with an addendum restricting use to Microsoft Flight Simulator.

full license text is in `LICENSE`. this mod is used only inside MSFS, which satisfies
the addendum.

for reference, roughly 70% of the classes in the shipped `FMC.js` are shared directly
with the base Working Title WT21 build, and most of the remainder are Working Title
CJ4 FMC framework classes.

**copyright (c) Microsoft Corporation. Working Title Simulations / Asobo Studio.**

## aircraft configuration

the `.cfg` and `.xml` files under `SimObjects/` are modified configuration for the
Sim Federation Challenger 350. base aircraft is theirs, you must own it.

## FMS extensions plugin

`lunar-challenger-350` is CaptainLunar's FMC extension work for the takeoff and
approach reference pages, plus ACARS and SimBrief datalink. included and continued
here with his permission.
